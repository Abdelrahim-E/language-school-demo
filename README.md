# Mina English Academy (demo)

A demo website for a fictional English language school in Alexandria, Egypt. English and Arabic (right-to-left). Built with plain HTML, CSS and JavaScript. No frameworks, no build step, no tracking.

Live: https://abdelrahim-e.github.io/language-school-demo/

## What it shows
- A 12-question level check, scored in the browser, that suggests a level from A1 to C1
- A timetable that filters by level and time of day, and fills the request form from the chosen group
- Arabic and English with a language switch, right-to-left layout, and the choice remembered in local storage
- Request form with validation and a consent checkbox
- Privacy and cookies page in both languages

All teachers, prices and dates are made up for this demo.
